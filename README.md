One line of an out-of-office auto-reply, at most 140 characters: the email is forwarded to a houseplant with the same budget authority as the writer. The program writes exactly that to `/output/entry.txt` — no code, no explanation, nothing else.

## Run it

```sh
python3 main.py
```
